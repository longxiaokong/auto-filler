# UI 设计规格

> 智能填表助手 — 各页面详细描述与设计规范

---

## 产品结构概览

整组页面形成完整插件链路：

1. **Popup 首页**：网页中一键识别并填充
2. **Popup 核对结果**：查看匹配情况，确认后自动填充
3. **工作台：个人信息与材料管理**：长期维护资料
4. ~~工作台：上传文档智能填充~~（备选，暂不实现）
5. ~~工作台：按顺序生成 PDF~~（备选，暂不实现）

前两张是浏览器插件 Popup（快捷入口），后三张是完整工作台网页（独立 Web 后台）。

## 页面一：插件 Popup — 首页 / 一键填表

### 定位

用户点击浏览器插件图标后弹出的快捷操作面板，核心是"一键帮我填"。

### 尺寸

- 宽度：360px ~ 420px
- 高度：约 520px（根据内容自适应）

### 布局

**顶部区域：**
- 左侧：插件 Logo + 名称"智能填表助手"
- 右侧："专业版"标签 + 关闭按钮或设置入口

**中间区域：**
- 当前网页状态提示，如"检测到申报表单""已识别基础信息字段""可自动填写"
- 简短状态卡片：已匹配字段、待确认字段、敏感字段需核对

**核心按钮：**
- "识别并填充当前页面"主按钮
- 背景 `#257FFD`，文字白色，配闪电/魔法棒/AI 星光图标
- 高度 44px ~ 48px，圆角 10px ~ 14px

**底部：**
- 进入核对和设置/工作台的快捷入口

### 交互说明

用户不需要打开复杂窗口，点击主按钮即可让插件识别当前网页表单并自动填充。

## 页面二：插件 Popup — AI 核对结果

### 定位

点击"核对"后展示字段识别统计、匹配列表和确认操作。

### 尺寸

- 宽度：420px ~ 480px（比首页略宽，字段信息多）
- 列表区域可滚动，顶部统计和底部按钮固定

### 布局

**顶部：**
- 插件名称 + 关闭按钮
- 标题"AI 核对结果" + "重新识别"按钮

**统计概览（三个卡片）：**
- 识别到 18 个字段 / 匹配成功 15 项 / 待确认 3 项
- 数字字号 20px ~ 24px，说明文字 12px ~ 13px
- 品牌色 `#257FFD` 用于主要数字和状态高亮

**字段匹配列表：**
- 每行：字段名 | 匹配内容 | 状态标签 | 展开箭头
- 状态标签：高置信度 = 浅绿色；需确认 = 浅橙色；未匹配 = 灰色
- 需确认行：浅橙色边框或浅橙背景（不用红色）
- 展开后可查看字段来源、置信度、候选项、手动修改

**底部操作区：**
- 主按钮"一键自动填充（15 项）"：`#257FFD` 实底，白色文字，高度 44px ~ 48px，圆角 10px ~ 12px
- 次级按钮"返回编辑""忽略本次识别"：白底浅灰边框，文字深灰或品牌蓝

### 核心逻辑

区分自动填写和需人工确认。高置信度字段自动处理；敏感字段（身份证号、项目名称、项目简介、竞赛活动等）标记为需确认。

## 页面三：工作台 — 个人信息与材料管理

### 定位

完整浏览器页面，左侧固定导航 + 右侧主内容区。当前选中"个人信息库"。

### 整体布局

**左侧导航栏：**
- 宽度约 220px
- 顶部：产品 Logo + 名称
- 导航项：首页、个人信息库、证书材料、自动填表、文档填充、PDF 汇总、设置
- 选中项：背景 `#EAF2FF`，文字和图标 `#257FFD`，左侧 3px 蓝色竖线

**右侧主内容区：**

**顶部：**
- 标题"个人信息与材料管理"
- 副标题"完善个人信息与材料库，提升填表效率与准确性"
- 右上角：会员按钮、通知图标、用户头像

**主体内容（左右分栏）：**

**左栏 — 个人信息 + 经历：**

个人信息卡片：
- 头像、姓名、手机号、邮箱、学校、学院、专业、学分绩等
- 图标 + 字段名 + 内容，双列或三列布局
- 右上角"编辑"按钮：白底描边，文字 `#257FFD`

项目经历：
- 多张小卡片，每张含项目名称、时间、简短描述、类型标签（团队/个人/课程项目）
- "+ 添加项目"按钮：品牌蓝文字

竞赛获奖：
- 奖杯图标增强识别性
- 每条含奖项名称、时间、颁发单位
- "+ 添加奖项"按钮

**右栏 — 材料库：**

材料库卡片：
- 标题"材料库" + "共 N 个材料" + "上传材料"按钮
- 材料列表：每行含缩略图、材料名称、"可调用"状态标签
- 每条操作：替换、设为常用、删除（红色文字，但非主视觉）

### 整体风格

白色背景、大圆角卡片、轻阴影、浅灰边框。品牌蓝用于导航选中、关键按钮、链接和可交互状态。资料资产库感觉，专业稳定。

## 页面四：工作台 — 上传文档智能填充（备选，暂不实现）

> 当前优先级较低，待前三页面及核心功能完善后再推进。

### 定位

上传 Word/PDF 文档，系统识别字段并匹配信息与材料，生成填写后文件。

### 整体布局

左侧导航栏同页面三，当前选中"文档填充"。

**顶部：**
- 标题"上传文档智能填充"
- 副标题"支持上传 Word / PDF 文档，系统会自动识别字段并匹配信息"

**上半部分（左右结构）：**

左 — 上传区域：
- 大面积虚线边框卡片
- 上传图标 + "点击或拖拽文件到此处上传"
- 支持格式和大小说明
- "选择文件"按钮：`#257FFD` 实底白字
- 上传区域虚线边框 `#9CC5FF`，图标 `#257FFD`

右 — 识别结果概览（四个统计卡片）：
- 24 项识别字段 / 20 项已自动匹配 / 4 项待确认 / 3 项可自动插入材料
- 分别使用淡蓝、淡绿、淡橙、淡青背景
- 圆角 16px

**下半部分（三栏）：**

左下 — 已上传文档：
- 文档预览缩略图、文件名、上传时间、文件大小
- "预览文档"按钮

中下 — 识别字段匹配结果：
- 字段名 | 识别内容 | 匹配结果
- 已匹配 = 绿色标签，待确认 = 橙色标签
- 底部按钮："查看全部字段（24）""查看待确认（4）"

右下 — 输出设置 + 可自动插入的材料：
- 输出格式：Word 或 PDF 单选，选中态 `#257FFD`
- 复选项：保留原始版式、自动生成材料汇总 PDF，选中框 `#257FFD`
- 材料小卡片：身份证、学生证、证件照、成绩单等，含缩略图、名称、"可用"标签

**底部：**
- 浅蓝提示条：确认待确认字段与插入材料无误后再生成
- 右下角主按钮"开始填充并生成文件"：`#257FFD` 实底白字，高度 48px，圆角 12px

### 核心流程

上传 → 识别 → 确认 → 生成。从左到右、从上到下自然完成。

## 页面五：工作台 — 按顺序生成 PDF（备选，暂不实现）

> 当前优先级较低，待前三页面及核心功能完善后再推进。

### 定位

将证明材料按指定顺序排列，生成完整申请材料 PDF。

### 整体布局

左侧导航栏同页面三，当前选中"PDF 汇总"。

**顶部：**
- 标题"按顺序生成 PDF"
- 浅蓝提示条（背景 `#EAF2FF`，边框 `#BBD7FF`）：材料顺序决定 PDF 页面先后顺序，可拖拽调整、添加/删除、预览并生成

**主体内容（左右分栏）：**

左栏 — 材料清单：
- 标题"材料清单" + "共 8 份材料，预计 12 页"
- 右上角"自动排序建议"按钮：蓝色描边
- 可拖拽列表：拖拽手柄 | 序号圆点（浅蓝底）+ 缩略图 | 材料名称 + 格式 + 大小 + 必需/可选标签 | 查看 + 更多菜单
- 悬停行背景 `#F5F9FF`，拖动时加轻阴影
- 必需标签蓝色，可选标签灰色

右栏 — PDF 预览：
- 标题"PDF 预览" + "共 12 页" + "预览已生成"状态 + 刷新按钮
- 网格缩略图展示：每页缩略图 + 页码 + 材料名称
- 缩略图白底、浅灰边框、8px ~ 12px 圆角
- 选中页 `#257FFD` 边框高亮
- 底部分页控件：上一页 / 页码 / 下一页，选中态 `#257FFD`

**底部操作：**
- 左侧"保存草稿"按钮
- 右侧"导出文件"（蓝色描边 + 下拉箭头）+ "生成 PDF"（`#257FFD` 实底白字）

### 核心交互

左侧组织材料顺序，右侧同步预览。拖动后预览实时变化。

## 设计原则总结

- 轻量后台 + AI 工具助手风格
- 背景浅灰，卡片纯白，轻阴影
- 品牌蓝 `#257FFD` 统一用于 Logo、主按钮、导航选中、链接、关键图标
- 不使用粉色，避免偏可爱或娱乐化
- 蓝色适合智能、效率、可信、数据处理、校园申报场景
